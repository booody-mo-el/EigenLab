# EigenLab — مختبر الاتجاهات الذاتية

موقع تعليمي تفاعلي يشرح المتجهات والقيم الذاتية بصريًا، مع محاكاة هندسية لمصفوفة ثنائية الأبعاد وأمثلة وتمرين قصير. يبدأ الموقع بالعربية، ويمكن تبديل الواجهة إلى الإنجليزية أو التبديل بين الوضعين الفاتح والليلي؛ تُحفظ التفضيلات محليًا في المتصفح.

**Add by: Abdelrahman Mohamed Elmetwally Yassin**

## التشغيل

بعد فك الضغط، افتح `index.html` في متصفح حديث. لا يحتاج الموقع إلى تثبيت مكتبات أو خادم؛ كل الحسابات تعمل محليًا في المتصفح. ويمكن أيضًا تشغيل خادم محلي من المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## اللغة والمظهر

- استخدم زر `EN` أعلى الصفحة للتبديل من العربية إلى الإنجليزية؛ يتغير اتجاه الصفحة تلقائيًا، ويصبح الزر `عربي` للعودة.
- استخدم زر `ليلي` للتبديل إلى الوضع الليلي؛ يتحول إلى `نهاري` للعودة إلى الوضع الفاتح.
- يحفظ الموقع اللغة والثيم المختارين في `localStorage` ويستعيدهما عند فتحه مجددًا في المتصفح نفسه.
