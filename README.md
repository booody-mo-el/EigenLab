# EigenLab — مختبر الاتجاهات الذاتية

موقع تعليمي تفاعلي بالعربية لشرح المتجهات والقيم الذاتية بصريًا، مع محاكاة مصفوفة ثنائية الأبعاد وأمثلة وتمرين قصير.

## التشغيل

بعد فك الضغط، افتح `index.html` في متصفح حديث. لا يحتاج الموقع إلى تثبيت مكتبات أو خادم؛ كل الحسابات تعمل محليًا في المتصفح. ويمكن أيضًا تشغيل خادم محلي من المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تعديل الاسم

في أسفل `index.html`، استبدل `Body Mo` بالاسم الذي تريده قبل تسليم المشروع.
